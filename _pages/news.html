{% comment %} News is read at page load from the URL in _config.yml (news_source) — typically a GitHub Gist raw link — so items can be updated without touching this repository. Expected format in that file, one block per item: ## 2026-09-10 | Paper accepted at MICCAI 2026 Body text. Supports **bold**, *italic*, `code` and [links](https://example.com). A blank line starts a new paragraph. The date part (before the "|") is optional. Newest first is recommended — items render in the order they appear in the file. {% endcomment %}
